Privacy policy

rocinante mail · Effective 25 November 2026

rocinante mail is a personal tool operated by Alejandro Patterson ("the owner") for the owner's own Gmail account. This policy explains what Google user data it accesses and how that data is handled.

Data accessed

When the owner signs in with Google, the app requests these permissions:

  • gmail.modify: to search and read messages, apply and remove labels, and create drafts.
  • gmail.settings.basic: to create and manage mail filters.

The app does not send email. Sending has been removed from its software.

How the data is used

Data is used only to carry out tasks the owner asks for in the owner's own mailbox, such as finding messages, sorting them and preparing drafts for the owner to review. It is not used for advertising, profiling or any purpose unrelated to those tasks.

Where the data is stored

The sign-in token is stored on the owner's private server, readable only by a dedicated system account. Message content is fetched when a task needs it. Copies are kept on that server only where a task requires it, for example a downloaded attachment.

Sharing

Google user data is not sold, rented or shared with third parties. To carry out a task, message content may be processed by the AI model service the owner uses to run the assistant, acting on the owner's instructions. It is not used to train AI models. No person other than the owner has access.

Limited Use

rocinante mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The owner can withdraw access at any time at myaccount.google.com/permissions. Withdrawing access stops all further use. Locally stored tokens and copies are then deleted from the server.
