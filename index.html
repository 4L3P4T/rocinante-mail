rocinante mail

A personal email assistant run by Alejandro Patterson

rocinante mail is a private tool that helps its owner manage one personal Gmail account. It runs on the owner's own home server and is not offered to anyone else.

What it does

With the owner's permission, it can search and read messages, apply and remove labels, create filters and prepare draft replies. It cannot send email: sending has been removed from the software, and every draft is reviewed and sent by the owner personally.

Who can use it

Only the owner. There is no public sign-up, and no other person's account is connected.
